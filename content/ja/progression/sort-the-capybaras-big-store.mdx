## Sort the Capybaras の実際の仕組み

基本はマッチングパズルです。カピバラは、プレイしているバージョンに応じて色、帽子、アクセサリー、ポーズなどの異なる種類でボード上に現れ、あなたの仕事はそれらを同じグループに動かして消し、スペースを空けることです。

ボードがいっぱいになり、有効な手がなくなると、そのランは終了します。この単純な失敗状態がゲームに緊張感を与え、進行度がそれほど重要になる理由でもあります。解放するアップグレードはどれもボードを少しだけ寛容にし、プールに追加する新しいカピバラの種類はどれもセットの作り方を変えます。

ループは簡単に説明できます：

- ボードをクリアしてコインを稼ぐ
- そのコインをショップでカピバラの種類、ブースター、ボードスペースに使う
- 新しい解放要素を使って、より難しいボードをクリアする
- 難しいボードほど報酬が良く、それが次の解放の資金になる

| ループ段階 | 何が起こるか | 何が解放されるか |
|---|---|---|
| 序盤のボード | 単純なセット、広めのスペース | コインとメカニクスの感覚 |
| 初めてのショップ訪問 | 小さな買い物、1〜2個のアップグレード | 追加スロットまたは基本ブースター |
| 中盤 | 密度の高いボード、狭いスペース | 新しいカピバラの種類とより強力なブースター |
| 終盤 | 無駄な手が罰になるボード | 見た目目標とコンプリート向け解放 |

コミュニティの報告では、序盤は寛容で、中盤は不注意な一手でランが終わり得る地点だと一貫して説明されています。その瞬間から、Sort the Capybaras のビッグストアは目新しさではなく、実際の戦略の一部になります。

### 最初に買うべきもの

Sort the Capybaras のビッグストアを、少ないコインで眺めているなら、一番かわいく見えるものを買いたい衝動は抑えましょう。プレイヤー経験からは、単純な順序が最も効果的です：

1. **ボードスペースを増やすもの。** スペースが増えれば余裕が生まれ、余裕が生まれれば行き詰まりが減ります。
2. **信頼できるブースターを1つ。** シャッフルかアンドゥを1つ持っておくだけで、連勝を台無しにするはずだったランを救えます。
3. **新しいカピバラの種類を2つほど。** 多様性はボードを面白く保ちますが、同時に扱うセットの種類も増やします。
4. **見た目アイテムは最後。** 楽しいですし、最終的には価値があります——ただし、基本が固まる前ではありません。

|---|---|---|---|

最もよくある罠は、Sort the Capybaras のビッグストアを順番に埋めていく買い物リストとして扱うことです。そうではありません。これは道具箱であり、正しい購入は現在あなたのランを殺しているものに完全に依存します。スペースが足りなくなるなら、スペースを買いましょう。ミスが多すぎるなら、ブースターを買いましょう。同じカピバラに飽きただけなら、そのときに多様性が効いてきます。

## 進行を加速する仕分け戦略

良い仕分け習慣は複利のように効きます。効率的に仕分けるプレイヤーはコインを早く稼ぎ、それはストアへの訪問回数を増やし、全体的な進行をより滑らかにします。

| 戦略 | 適用方法 | うまくいく理由 |
|---|---|---|
| 置く前にグループ化 | まず既存のペアやトリプルを探す | 一致するカピバラを散らばらせるのを防ぐ |
| 退避レーンを確保 | 1エリアを意図的に空けておく | はぐれたカピバラを置く場所を作る |
| 端から内側へ作業 | 中央より先に外側のグループを消す | 中央の柔軟性を保つ |
| 投入キューを確認 | 次に何が来るかを踏まえて計画する | 不意の行き詰まりを減らす |
| ブースターを温存 | 本当の壁のために取っておく | 確実な敗北をクリアに変える |
| 「十分良い」を受け入れる | 完璧なボードを追うのをやめる | 手数と時間を節約する |

さらに上乗せする価値のある習慣がいくつかあります：

- **動かす前に数える。** 2秒の確認で、明白な手より良い初手が見つかることがよくあります。
- **完成したセットを崩して、散らかったセットを直さない。** 完成したセットは進行であり、散らかったセットはただのノイズです。
- **短く、集中したセッションでプレイする。** 長いセッションは自動操縦を招き、自動操縦は無駄な手を生みます。
- **昔のボードに戻る。** 大きな買い物のために貯めているとき、簡単なクリアは最も信頼できるコイン源です。

## コイン、アップグレード、支出の優先順位

コインは Sort the Capybaras のビッグストアにあるすべての燃料なので、どれだけ早く稼ぐかよりも、どう使うかの方が重要です。単純な優先順位があれば、苦労して貯めた残高を無駄にせずに済みます。

| 優先度 | 投資先 | 理由 |
|---|---|---|
| 1 | ボード容量 | 失敗状態を直接減らす |
| 2 | 中核ブースターを1〜2個 | 敗北をクリアに変える |
| 3 | 新しいカピバラの種類 | 多様性と新しいセットの選択肢を追加 |
| 4 | 便利アップグレード | 今後のコイン稼ぎを加速 |
| 5 | 見た目アイテム | 楽しみのみで、性能面の利得なし |

プレイヤー経験から得られる経験則が2つあります：

- **余裕を残す。** 一度の訪問で残高をすべて使わないでください。少しの予備があれば、特定のボードに何度も負けるときに反応できます。
- **目の前の問題に合わせて買う。** ストアは、セールのものをすべて買うプレイヤーよりも、自分の弱点を診断できるプレイヤーに報います。

*いつ*買うかを考えるのも役立ちます。大きなコイン稼ぎの直後に買うのは気分が良いですが、何度も失敗しているボードに挑む直前に買う方が良い結果を生みやすいです。明確な目標を持って使えるからです。

## 進行を遅らせるよくあるミス

Sort the Capybaras で進行が止まるほとんどの原因は、不運ではなく、いくつかの繰り返しのミスに帰着します。

## よくある質問

**Sort the Capybaras のビッグストアは、コインを使う価値がありますか？**
はい、ただし1つ条件があります：結果を変えるものに使いましょう。ボード容量とブースターは結果を変えます。見た目アイテムは変えません。迷ったら、何度も遭遇する特定の失敗を防ぐアップグレードを買いましょう。

**ストアで最初に何を買うべきですか？**
まずボードスペースを増やすものを選び、次に信頼できるブースターを1つ追加しましょう。この2つの購入は、少ない支出でクリア率を最も大きく跳ね上げやすく、その後のすべての購入をより手頃にします。

**ゲームをクリアするには、すべてを買う必要がありますか？**
いいえ。コミュニティの報告では、ほとんどの進行目標は厳選したアップグレード一式で達成できます。コンプリート勢はいずれ見た目アイテムや便利アイテムも欲しくなりますが、ボードをクリアする上では任意です。

**ストアにまったく行かずに進行できますか？**
ある程度は進めますが、ボードの密度が上がると進行は劇的に遅くなります。Sort the Capybaras のビッグストアは難易度曲線を公平に保つために存在しており、完全に無視するということは、最初に持っていた道具だけで毎回の難しいボードに挑むことを意味します。
