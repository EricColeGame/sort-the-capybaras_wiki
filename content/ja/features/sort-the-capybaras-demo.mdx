## 仕分けパズルの仕組み

ルールセットは4行で説明できるほど小さく、それがこのジャンルがスマートフォン、タブレット、デスクトップのいずれでもうまく機能する大きな理由です。本当のスキルはルールを覚えることではなく、何も触る前に盤面を読むことを学ぶことです。

| 状況 | 可能か？ | 理由 |
|---|---|---|
| カピバラを空きスロットに移動する | はい | 空の容器は作業スペース |
| カピバラを同じ種類の上に移動する | はい | これが基本の積み上げルール |
| カピバラを違う種類の上に移動する | いいえ | パズルを生み出すルール |
| 埋もれているカピバラを持ち上げる | いいえ | 一番上のピースだけが移動可能 |
| 揃ったスタックを一度にまとめて移動する | ビルドによる | 複数ピースの移動を許可するバージョンもある |
| 「ロックされた」容器から取り出す | 一部のビルドでは不可 | 特定のレベルでは解決するまで容器が制限される |

簡単な例の盤面：2つの容器に2種類のカピバラが混ざって入っており、3つ目の容器が空いています。最初の直感は、一番上のカピバラを空きスロットに移すことかもしれません。しかし、そのピースが自分の容器の底にすでに座っている種類のものであれば、唯一の空きスペースを無駄に使ってしまったことになります。

それがこのジャンル全体が築かれている罠です。すべての手はスペースを生み出すか消費するかのどちらかであり、デモの役割は、鍵を渡す前にその緊張感を何度か味わわせることです。

### 動かす前に盤面を読む

経験豊富なプレイヤーは決まった順序でスキャンします：種類を数え、容器を数え、どの種類の着地可能な場所が最も少ないかを見つけます。最も「追い詰められている」種類が、通常最初の3～4手を決定づけます。その制約から外側へと作業を進める方が、1タップずつ反応するよりはるかに信頼できます。

## 操作、快適さ、アクセシビリティ

仕分けゲームは操作感で生きるか死ぬかが決まります。わずかに遅れて反応するタップ、あるいは間違った容器に吸い付くカピバラは、それ以外は洗練されたパズルを台無しにします。幸いなことに、このスタイルのゲームは技術的にシンプルで、ほとんどのビルドは基本を正しく押さえています。

| 入力 | 動作 |
|---|---|
| 容器をタップまたはクリック | 一番上のカピバラを持ち上げる |
| 移動先をタップまたはクリック | そこにカピバラを落とす |
| ドラッグして離す | ピースを直接移動（ビルドによる） |
| 元に戻すボタン | 直近の手を元に戻す |
| リスタートボタン | レベルを開始状態にリセット |
| ヒントボタン | 推奨される次の手を表示 |

ゲームを評価する前に、いくつかの快適機能を確認する価値があります。色覚異常に配慮したパレットやパターンオーバーレイを探しましょう。一部のビルドではカピバラの種類を主に色で区別しているからです。序盤のレベルがタイマー制かどうかを確認しましょう — ほとんどのデモはそうではありませんが、中にはそういうものもあり、タイマーはカジュアルパズルの雰囲気全体を変えてしまいます。

プレイヤーの経験からも、サウンドをオンにしてプレイすることが思った以上に役立つことが示されています。合法か違法かのドロップに対する小さな音声キューは、特に小さな画面では、アニメーションを見るよりも速くフィードバックを与えてくれます。

## デモ内の難易度曲線

デモは通常、意図的な傾斜を中心に作られています。序盤のレベルは教えるために存在し、中盤のレベルは自信をつけるために存在し、最後のレベルは完全版を欲しがらせるために存在します。その進行が通常どのように展開するかを以下に示します。

| 段階 | 教えること | 典型的な複雑さ |
|---|---|---|
| 序盤のレベル | 積み上げルールと元に戻す | 2種類のカピバラ、空の容器1つ |
| 初期のレベル | 2手先を計画する | 3種類、より少ない容器数 |
| 中盤のレベル | 空きスペースの管理 | 埋もれたピースがある3～4種類 |
| デモ最終レベル | 階層的で多段階の解決策 | 4種類以上、空きスロットがより少ない |

レベルと種類の正確な数はビルドによって異なりますが、形は一貫しています：デモの最後の1～2レベルは、意図的に、その前のレベルよりもほとんど常に難しいのです。

デモの終わり近くで行き詰まったなら、それは注意を払う価値のあるシグナルです。それはあなたがゲームが下手だという意味ではなく、パズルが仕事を果たしているという意味です。問題は、行き詰まることが楽しい挑戦と感じられるか、それとも苛立ちと感じられるかです。その答えは、どんなトレーラーよりも、完全版を買うべきかどうかを教えてくれます。

## 実際に役立つコツと戦略

カピバラ仕分けパズルでの失敗のほとんどは、同じいくつかの癖から来ています。それらを直す方が、レベルを延々と攻略するよりも速いです。

- **常に容器を一つ空けておく。** 空きスペースこそが、あなたが本当に管理している資源です。すべてのスロットを埋めると盤面はロックします。
- **下から上へ解く。** まず各容器の一番下のカピバラを見てください — それらが最も解放しにくいピースです。
- **決断する前に数える。** 各種類を3秒数えるだけで、ほとんどの行き詰まりを防げます。
- **元に戻すを情報として使う、失敗としてではなく。** 手を戻すことで、パズルのどの分岐が間違っているかがわかります。
- **一つの容器を完全に仕上げる。** 完全に仕分けられた容器は変数でなくなり、問題が小さくなります。

| よくある間違い | なぜ悪いか | より良い習慣 |
|---|---|---|
| 欲張りな仕分け | 唯一の空き容器を埋めてしまう | 操作のためにスロットを一つ確保する |
| 埋もれたピースを無視する | 多くの手の間、容器を塞いでしまう | まずそれらを露出させる方法を計画する |
| 同じピースを繰り返し動かす | 進展なく手を浪費する | 3手分の計画にコミットする |
| 早すぎるリスタート | ほぼ解決した盤面を失う | リスタートする前に元に戻すを2回試す |
| すぐにヒントを求める | 学びの瞬間を逃す | 一つの計画を試してからヒントを確認する |

類似の仕分けゲームのプレイヤーからのコミュニティ報告は、一貫して同じ転換点に言及しています：「どの種類が最も行き先が少ないか」という観点で考え始めると、レベルは目に見えて簡単になります。その一つの思考の転換は、どんなヒントボタンよりも効果があります。

## よくある質問

**sort the capybaras デモは無料でプレイできますか？**
はい — デモは定義上、ゲームの無料部分です。ほとんどのビルドでは含まれるレベルを支払いなしでプレイできますが、通常、利用可能なコンテンツの終わりに到達すると、完全版のロックを解除するよう促すプロンプトが表示されます。

**デモをクリアするのにどのくらいかかりますか？**
それはメカニクスがあなたにとってどれだけ早く飲み込めるかによります。ほとんどのプレイヤーはチュートリアル形式のレベルをそれぞれ数分で進みますが、行き詰まって元に戻すかリスタートする必要がある場合、最後のレベルはかなり長くかかることがあります。

**進行状況は完全版に引き継がれますか？**
それはビルドとプラットフォームによって異なります。進行状況をローカルに保存して引き継ぐバージョンもあれば、デモを独立した体験として扱うものもあります。何も決めつける前に、ストアページやゲーム内設定を確認する価値があります。

**楽しむためにカピバラについて何か知っている必要がありますか？**
いいえ。カピバラのテーマは魅力であって、メカニクスではありません。ピースがげっ歯類であれ、ビー玉であれ、色付きの水であれ、どんな仕分けパズルも同じように機能します — カピバラはただ、全体をかなり見ていて楽しいものにするだけです。
